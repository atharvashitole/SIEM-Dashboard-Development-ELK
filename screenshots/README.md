# Screenshots

## Overview

This folder contains screenshots captured throughout the implementation of the SIEM Dashboard Development Using ELK Stack project.

The screenshots provide visual evidence of environment configuration, security event ingestion, detection rule creation, alert generation, dashboard development, and validation activities.

## Folder Structure

### environment-setup
Contains screenshots related to:
- Docker container deployment
- Elasticsearch configuration
- Kibana setup
- Initial environment verification

### brute-force-detection
Contains screenshots demonstrating:
- Brute Force event ingestion
- Detection rule configuration
- Alert generation and validation

### privilege-escalation-detection
Contains screenshots demonstrating:
- Privilege Escalation event ingestion
- Detection rule configuration
- Alert generation and validation

### data-exfiltration-detection
Contains screenshots demonstrating:
- Data Exfiltration event ingestion
- Detection rule configuration
- Alert generation and validation

### dashboard-development
Contains screenshots related to:
- Security Events Dashboard creation
- Metrics visualizations
- Event type analysis
- Severity monitoring
- Source IP analysis
- Event monitoring tables

### testing-validation
Contains screenshots demonstrating:
- Rule execution verification
- Alert validation
- Dashboard functionality testing
- Final monitoring results

## Purpose

These screenshots document the complete implementation process and validate the successful development of a custom SIEM dashboard for monitoring critical security events using the ELK Stack.
