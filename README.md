# SIEM Dashboard Development for Security Event Monitoring Using ELK Stack

## Overview

This project demonstrates the design and implementation of a Security Information and Event Management (SIEM) dashboard using the ELK Stack (Elasticsearch and Kibana).

The solution was developed to monitor and visualize critical security events including:

- Brute Force Attacks
- Privilege Escalation Attempts
- Data Exfiltration Activities

Security events were ingested into Elasticsearch, analyzed using custom Elastic Security detection rules, and visualized through an interactive Kibana dashboard.

## Key Features

### Security Event Ingestion

Created and indexed simulated security events representing multiple attack scenarios.

### Detection Engineering

Developed custom detection rules for:

- Brute Force Detection
- Privilege Escalation Detection
- Data Exfiltration Detection

### Alert Generation

Validated rule execution through Elastic Security alerts and event monitoring.

### Dashboard Development

Created visualizations including:

- Total Security Events
- Severity Metrics
- Attack Type Distribution
- Severity Distribution
- Source IP Analysis
- Recent Security Events Monitoring Table

### Testing and Validation

Verified successful event ingestion, alert generation, dashboard functionality, and visualization accuracy.
